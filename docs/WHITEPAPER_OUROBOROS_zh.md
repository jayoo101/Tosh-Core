## 1. 摘要

Ouroboros 分三个阶段发行代币：

| 阶段 | 内容 |
|---|---|
| **L1（2 小时）** | 每份 0.9 USDT，只限时间、不限总量；结束后按份数平分 L1 代币 |
| **L1.5** | 开盘领币；铸造关闭；尚未建池，只能通过买单换手 |
| **L2（次日）** | 按开盘价建池并开放交易；按阶梯价铸造；铸造资金买入再加池；等量销毁 |

**核心口号：铸一分，烬一分。**

---

## 2. 意象与用语

**Ouroboros（衔尾蛇）** 表示生与灭连成闭环：L2 每铸出一份代币，底池同时销毁对应数量，铸造资金同时加入流动性。

| 用语 | 含义 |
|---|---|
| 铸一分，烬一分 | L2 销毁量与用户所得数量相同 |
| 开盘价 | 参考 L1.5 成交价设定，不低于 L1 认购价 |
| 换手窗口 | L1.5 期间只通过买单成交的市场 |

---

## 3. 代币总量

- 总量上限 **21,000,000,000 枚**（210 亿），写入代币合约，超出部分无法铸造。  
- L1 结束时生成 5/9，分给 L1 参与者；L2 建池时最多生成 4/9，注入官方池子。开盘价高于 L1 价格时生成更少，未生成部分永久不再生成。  
- L2 每铸出一份代币，底池同时销毁相同数量，总量不变。  
- L2 起卖出税 1% 销毁，总量只减不增。  
- 无预售、无团队预留、无私募份额。

---

## 4. 参与条件

- 持有有效的 Binance `.ai` **Agent ID**。  
- 每个 Agent ID 在 **L1 + L2 合计最多 30 份**；单笔最多 30 份。  
- 无有效 ID 或份数用尽时，无法继续铸造。  
- 铸造须由持有 Agent ID 的钱包直接发起，合约钱包与代调用合约无法铸造。  
- Agent ID 注册表由币安维护；注册表异常期间无法铸造，恢复后即可继续。

## 5. 生命周期

| 阶段 | 时间 | 铸造 | 市场 |
|---|---|---|---|
| **L1 播种** | 2 小时 | 开 | 一口价认购；代币不可交易 |
| **开盘（L1.5 开始）** | L1 结束时 | 关 | L1 代币开放领取；买单簿开启；尚未建池 |
| **L1.5 换手** | 开盘后至次日 L2 开启 | 关 | 只能挂买单、不能挂卖单 |
| **L2 扩容** | 次日开启 | 开 | 按开盘价建池，LP 永久锁定，池子开放交易；阶梯铸造、加池、等量销毁 |

各阶段的具体时间以官网倒计时为准。

---

## 6. L1 播种

- 持续 **2 小时**；只限时间、不限总量：在此期间，凡符合资格的用户均可参与，每个 ID 最多 30 份。  
- 每份 **0.9 USDT**，可用 USDT 或 BNB 支付（见第 12 节）。  
- L1 结束时，**11,666,666,667 枚**（总量的 5/9）按份数平分给全体 L1 参与者：  
  `每份代币数 = 11,666,666,667 ÷ L1 总份数`  
- **20%** 进入项目金库，**80%** 由铸造合约保管，L2 开启时用于建池。  
- L1 认购总额决定建池规模。  
- L1 期间代币不可转让；开盘后参与者即可领取 L1 代币。

---

## 7. 开盘

L1 结束即进入 L1.5：L1 参与者领取代币，买单簿开启。此时**尚未建池**，官方交易对没有流动性，任何人都无法向其中转入代币。

L2 开启时，协议将 L1 募集的 80% USDT 全部注入 PancakeSwap V2，并按开盘价配入代币，最多 **9,333,333,333 枚**（总量的 4/9）；所得 LP 发送至不可取回地址，永久锁定。建池由多签任一签名人在 L2 开启后发起，建池与开放交易在同一笔交易内完成；建池前，L2 铸造与池子交易均不开放。L2 开启满 3 天仍未建池时，任何人都可发起建池，开盘价为 L1 价格。

开盘价由签名人在建池时参考 L1.5 成交价填写，合约执行以下规则：

- 开盘价不低于 L1 价格（L1 每份成本对应的单枚价格）；填写价格低于 L1 价格时，按 L1 价格建池。  
- L1.5 买单簿累计成交额不足 L1 募集总额的 **5%** 时，按 L1 价格建池。  
- 按 L1 价格建池时注入全部 4/9；开盘价高于 L1 价格时，注入数量按价格相应减少，其余部分永久不再生成。

---

## 8. L1.5 换手

- **只能挂买单**（买方锁定 USDT），**不能挂卖单**；持币人通过成交现有买单卖出。  
- 此阶段所有买卖均通过买单簿完成。  
- 成交价由挂单与吃单决定；没有买单时无法卖出。  
- 买单簿成交收取 L1.5 交易税（见第 13 节）。

---

## 9. L2 扩容

- 开启时先按开盘价建池（见第 7 节），池子随即开放交易。  
- 阶梯价从 L2 **第 1 份**起算（L1 份数不计入），起步 **1.20 USDT/份**，随 L2 累计份数上涨，完整档位见[附录 A](#附录-a--l2-阶梯价)。  
- L2 共 **21,000,000 份**，铸满即停。  
- 得币数量 = 支付金额 ÷ 本笔资金加池后的池价 × 1.01。  
- 单笔支付不超过池子 USDT 的 10%；池子较浅时，单笔可铸份数相应减少。  
- 与 L1 共用每个 ID 的 30 份额度。  
- 可用 USDT 或 BNB 支付（见第 12 节）。  
- **20%** 进入金库，**80%** 用于加池。

---

## 10. 等量销毁与加池

每笔 L2 铸造在同一交易内完成：

1. 校验身份、份数与单笔上限，完成分账；  
2. 80% 的支付用于买入代币并加入流动性；  
3. 按加池后的池价计算用户所得，代币进入领取合约；  
4. 从官方底池销毁与用户所得相同数量的代币。  

加池因滑点未完成时，该部分资金排队，在后续交易中加入流动性。  
加池所得 LP 永久锁定。

## 11. 领取

L2 铸造的代币在 **180 秒**后可领取。

## 12. 支付方式

L1 与 L2 均可用 **USDT** 或 **BNB** 支付：

- **USDT**：先授权，再铸造；合约按应付金额扣款，用户可设定愿意支付的最高金额。  
- **BNB**：按 Chainlink BNB/USD 价格加 1% 计算应付 BNB，合约在 PancakeSwap 将 BNB 换成 USDT 后结算。换得的 USDT 不足应付金额时，交易整体回滚；超出应付金额的 USDT 进入金库；多付的 BNB 原路退回。  
- 直接向铸造合约转账 BNB 或 USDT 不会触发铸造；任一校验失败时，整笔交易回滚，资金留在用户钱包。

无论用哪种方式支付，进入池子与金库的均为 USDT。

---

## 13. 交易税

| 阶段 | 场所 | 买入 | 卖出 |
|---|---|---|---|
| **L1.5** | 买单簿成交 | **2%** → 金库 | **2%** → 金库 |
| **L2 起** | 官方 TOKEN/USDT 交易对 | **1.25%** → 换成 USDT 进入金库 | **1%** → 销毁 |

- L1.5：买方税从买方所得代币中扣除，卖方税从卖方所得 USDT 中扣除，均直接进入金库。  
- 钱包之间转账不收税；铸造、销毁、加池、领取不收税。  
- 官方交易对是唯一的 AMM 市场：代币在任何阶段都无法转入或转出其他交易对与聚合流动性池。

## 14. 资金分流

| 来源 | 去向 |
|---|---|
| L1 支付 | 20% → 金库；80% → L2 建池流动性 |
| L1.5 交易税 | 买卖各 2% → 金库 |
| L2 支付 | 20% → 金库；80% → 加池 |
| L2 起买入税 | 1.25% → 换成 USDT → 金库 |
| L2 起卖出税 | 1% → 销毁 |
| BNB 支付换汇余额 | 超出应付金额的 USDT → 金库 |
| 官方 LP | 永久锁定 |

金库资金用于项目运营、营销与审计。

## 15. 管理与金库

- 项目金库与协议管理权限由 **Safe 多签**持有。  
- 总量、份数、阶梯价、税率、分账比例写入合约，上线后任何人都无法修改。  
- 多签仅可紧急暂停或恢复铸造、在 L2 开启后发起建池，以及管理金库资金；无法增发，也无法修改上述参数。  
- 多签地址、代币合约、铸造合约及官方交易对地址在官网公布，合约在 BscScan 开源验证。  
- 代币合约可从官方底池扣减代币，该权限仅用于 L2 铸造时的等量销毁。  
- 官方 LP 永久锁定，多签无法取回。

## 17. 主要风险

| 风险 | 说明 |
|---|---|
| 市价风险 | 价格可剧烈波动，可跌破建池价格，可归零 |
| 机制局限 | 销毁、加池、交易税均不保证价格或收益 |
| L1.5 卖出受限 | 池子未开放交易，只能卖给已有买单；买单不足时可能无法卖出或只能低价成交 |
| 交易成本 | L1.5 买卖各 2%；L2 起买入 1.25%、卖出 1%，另有 Pancake 手续费与滑点 |
| 流动性与滑点 | L1 认购少则建池规模小；铸造、加池与交易均可能有滑点 |
| 抢跑 | 池子较浅或单笔较大时，交易可能被抢跑；铸造与交易请设置滑点保护 |
| 单笔额度 | 单笔铸造受池子深度限制；L1 总份数少于 17 份时，L2 须待买入加深池子后才能铸造 |
| 身份边界 | 限额按 Agent ID 计算，一人持有多个 ID 时可多次参与 |
| 外部依赖 | Agent 注册表、Chainlink 报价、RPC、稳定币、路由器、区块环境均可能异常 |
| 建池发起 | 建池由多签签名人发起；发起前 L2 无法铸造与交易 |
| 开盘定价 | 开盘价由多签签名人填写，可高于 L1.5 成交价；开盘价越高，池中代币越少，同等卖出对价格的冲击越大 |
| BNB 支付 | 按报价加 1% 收取 BNB 并兑换为 USDT；兑换不足时交易失败，网络费用不退 |
| 合约与运营 | 漏洞、配置错误、前端故障、私钥管理问题均可导致损失 |
| 监管与准入 | 不同地区要求不同；前端可能限制访问；用户须自行合规 |
