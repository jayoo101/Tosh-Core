## 5.1 参与方（替换）

| 参与方 | 做什么 |
|---|---|
| 参与者 | 持有 Binance Agent ID，在创世期按曲线价买入，代币立即到账；开盘前可在官方买单簿卖出或在钱包之间转账；开盘后交易、购买货架 |
| 买家 | 任何钱包都可以在开盘前的官方买单簿挂买单，不需要 Agent ID |
| 开发者（项目方） | 通过平台审核后上架；持有项目的 Circuit NFT，领取 20% 募集资金、货架收入的 99%，并在创世结束后 48 小时内独家决定开盘时间 |
| 平台（2-of-3 Safe） | 审核与上架项目，维护回购名册，持有有边界的紧急制动；收取买单簿手续费和池子交易税中的平台部分 |

## 5.2 一个项目的生命周期（替换）

| 阶段 | 内容 | 由谁触发 |
|---|---|---|
| 上架 | 平台审核后调用 `createLaunch`，部署 Hook、代币、Circuit NFT 与收入金库 | 平台 |
| 创世发售 | 持有 Agent ID 的钱包按曲线价买入，越早越便宜，代币立即到账；窗口 3 / 24 / 72 小时，或提前卖完 | 参与者 |
| 开盘前市场 | 官方买单簿只显示买单，持币人可以卖给买单；钱包之间可以转账，链上不存在任何池子 | 任何人 |
| 开盘 | 80% 募集资金与对应代币按 2P 注入 Infinity 池并永久锁定，未卖出的创世代币销毁，转账限制解除 | 卖完或截止后 48 小时内由项目方触发，之后任何人 |
| 交易 | 二级市场自由买卖，买入税进回购金库，卖出税就地销毁 | 任何人 |
| 阶梯发行 | 4,000 档货架从 2P 起，在价格闸门内持续出售新供给 | 任何人 |
| 回购上榜 | TWAP 成熟后加入回购名册，金库开始为其买入并销毁 | 平台 |

v2 没有"领取"和"退款"阶段：买入即到账，买入即最终成交。

|---|---|

## 6.2 每个项目的参数（替换）

| 参数 | 范围 | 说明 |
|---|---|---|
| 计价币 | BNB（内部为 WBNB）或 USDT | 由选择的工厂决定 |
| `hardCap`（H） | BNB 项目 1 – 500 BNB；USDT 项目 500 – 300,000 USDT | 卖完时的募集总额；第一枚价格 P = H ÷ 7,000,000 |
| `perAgentCap` | BNB 项目固定 0.1 BNB（每份 0.01 BNB，最多 10 份）；USDT 项目 5 – 30,000 USDT（平台可调整范围） | 每个 Agent ID 在本项目最多花多少 |

## 7. Binance Agent ID：一个身份一份额度（替换整章）

### 7.1 为什么换成 Agent ID

v1 用历史 gas 度量钱包，需要链下扫描服务和一把签名私钥，这把私钥是整个准入流程的单点。v2 改为直接读取 BNB Chain 上的 Binance Agent ID 注册表（SPACE ID 发行的 `.ai` 名字，`0x60B9…B022F`）：

- Agent ID 不可转让、永久有效，一个 Binance 账户只能领取一个；
- 合约在买入时直接读注册表，平台不运行任何签名服务，也不保管任何准入私钥。

### 7.2 怎么校验

创世买入时，Hook 依次读取：

1. `handleOf(买家)`：为空则拒绝；
2. `ownerOfHandle(名字) == 买家`：两次读取一致才算持有；
3. 额度按名字的哈希记账，而不是按地址。名字即使换绑到别的地址，也不能再领一份额度。

两次读取都限定 gas 上限。注册表出问题时只有创世买入暂停，开盘、转账和买单簿不受影响。

### 7.3 谁能参与，怎么参与

- 买家必须是交易的发起人：普通钱包和 EIP-7702 账户都可以，合约钱包（Safe 等）不行。
- Agent ID 绑定在 Binance Agentic Wallet 上，而 Agentic Wallet 不能连接网页。网页把每一步写成指令，用户交给自己的 AI agent，在 Binance App 的开发者模式下执行。
- 2026 年 10 月链上抽查的 555 个 Agent ID 持有地址全部是普通钱包，交易由持有者本人直接签名。

### 7.4 额度

- 每个 Agent ID 在一个项目里最多花 `perAgentCap`，可以分多次买。
- 付多了不会多扣：实际成交额 = min(支付额, 剩余额度, 卖完所需金额)，BNB 项目多付的部分在同一笔交易里退回。

## 8. 创世发售与开盘（替换整章）

### 8.1 按卖出量线性涨价

创世期最多卖出 5,600,000 枚。已卖出 s 枚时，下一枚的价格是：

$$
\text{price}(s) = P \times \left(1 + 0.5 \times \frac{s}{5{,}600{,}000}\right), \quad P = \frac{H}{7{,}000{,}000}
$$

第一枚价格为 P，最后一枚为 1.5P，卖完时平均价 1.25P，募集总额正好是硬顶 H。越早参与越便宜；每个 Agent ID 有额度上限，抢先的好处有上界。

买入时代币立即铸给买家，没有领取步骤，也**没有退款**。剩余可售量低于 0.001 枚时视为卖完。

### 8.2 资金去向

每一笔买入当场记账：

- **20%** 记入项目基金，NFT 持有者随时可以提到 `projectFund`；
- **80%** 留作建池资金，开盘时全部进池。

记账而不是即时转账，是为了让任何地址都卡不住买入。v2 不设推荐佣金。

### 8.3 开盘前：只有买单的官方市场

开盘前代币已经在用户手里，但链上不能形成任何池子。代币合约在开盘前只允许下面两种转账：

| 情况 | 条件 |
|---|---|
| 钱包之间转账 | 发送方本人发起交易；收款方是钱包（普通钱包或 7702 账户），并且已登记为收款地址 |
| 买单簿成交 | 由官方买单簿发起，卖家本人发起交易，买家是已登记的钱包 |

参与过创世或挂过买单的钱包会自动登记；其他钱包要先自己发一笔登记交易。未部署的合约地址没有私钥，永远无法登记，所以"先打币、再部署合约"的绕法不成立。开盘前也只能授权给官方买单簿。

官方买单簿（`ToshBidBook`）：

- 任何钱包都可以挂买单，资金托管在合约里，随时可撤；页面上没有卖单。
- 挂单价不得低于当时的最新参与价；成交时，价格低于最新参与价 90% 的买单会被跳过。
- 买卖双方各付 1% 手续费，只在成交时收取，归平台。
- 开盘后停止挂单和成交，只能撤单。

### 8.4 开盘

- **时间**：卖完或创世截止后，48 小时内只有 Circuit NFT 持有者可以开盘；48 小时后任何人都可以，没有过期。开盘一定能完成：它不依赖注册表、不依赖项目基金地址，也不受工厂暂停影响。
- **建池**：80% 募集资金与 `0.8H ÷ 2P` 枚代币按开盘价 **2P** 注入 PancakeSwap Infinity 全区间流动性，仓位由项目合约持有，**没有任何撤出路径**。卖完时进池数量正好是 2,800,000 枚。
- **定价只看内部账目**：官方池只能由 Hook 初始化，价格与数量来自创世记账，不读合约余额。外部直接转入 Hook 的资金在开盘时转给平台，推不动开盘价。
- **销毁**：未卖出的创世代币铸入黑洞地址。
- **解除限制**：同一笔交易里解除全部转账限制，代币成为普通 ERC-20。不存在"限制已解除、官方池还没建好"的间隙。

### 8.5 开盘时参与者的账面

| 参与者 | 成本 | 开盘价 2P 相对成本 |
|---|---|---|
| 第一个 | P | 2.0 倍 |
| 平均 | 1.25P | 1.6 倍 |
| 最后一个（卖完时） | 1.5P | 1.33 倍 |

### 8.6 不设软顶，也不设最低募集额

没有退款，募集多少就按多少开盘。只要有人参与过，开盘就能完成；募集很少时池子会很浅，价格波动会很大（见第 17 节）。

## 9.2 货架参数（修改三行）

| 参数 | 值 |
|---|---|
| 每档数量 | 3,150 枚 × 募集额 ÷ 硬顶（向上取整，开盘时固定） |
| 阶梯总量 | 12,600,000 枚 × 募集额 ÷ 硬顶 |
| 第 0 档价格 | 开盘价（2P） |

**没募满，货架按比例缩小。** 开盘池的代币数量是 2,800,000 × 募集额 ÷ 硬顶，所以货架也按同一比例缩小：卖完时每档 3,150 枚；只募到一半时每档 1,575 枚。这样无论募了多少，每一档相对池子深度的占比都一样（约为池子代币侧的 0.11%），小项目的第一档不会一下子砸穿浅池。每档数量在开盘那一刻算出并写死，之后不再变化。

## 9.3 价格闸门（替换）

### 9.3 价格闸门：不高于市场价

货架第 i 档只在其价格不高于 $\min(\text{现价}, \text{TWAP})$ 时可售，即上限就是参考价本身（面值），不再上浮 5%。开盘后 30 分钟内，参考价取 $\min(\text{现价}, 2P)$，所以这段时间最多只能打开第 0 档。

- **货架永远不比市场便宜。** 能买到的每一档都不低于参考价，没有人能从货架低价买入再卖回池子套利。

- **给上涨踩刹车。** 池子价格明显高于已解锁的货架档时，套利者从货架铸币卖进池子，把价格拉回货架附近。扣除 1% 交易税和 0.3% LP 手续费后，套利只在池子价格高于货架价约 1.3% 以上时才有利可图，不会把价格砸到 2P 以下。
- **创世参与者不会被稀释到成本以下。** 货架最低价 2P，高于任何创世参与者的成本（P 到 1.5P）。
- **开盘区块关闭。** 开盘所在区块不允许铸币，阶梯从下一个区块开始。

## 12.3 收入权可以转让（替换）

Circuit NFT 是标准 ERC-721，可以转让或出售。每次转让时，合约会依次：

1. 结算创世仓位手续费，并把收入金库里的全部余额付给卖方；
2. 把项目基金里已记账、还没提取的 20% 募集资金，付到当前的 `projectFund` 地址；
3. 把 `projectFund` 改为买方地址。

所以**卖出 Circuit 只卖出未来的收入**：转让之前赚的钱属于卖方，买方从空金库、空基金开始，之后的项目基金也直接归买方，买之前不需要做任何核查。

## 14.2 平台能做什么、不能做什么（补充两条）

- 平台可以暂停某个项目或全部项目的**创世买入**，并屏蔽个别地址的创世买入；这不影响开盘、转账、撤单和成交。
- 平台不能改变任何项目的价格曲线、额度、资金分配和开盘规则，也不能动用买单簿里的托管资金。

## 17. 已知局限（替换第 2、3 条，并补充）

2. **准入依赖第三方注册表。** Agent ID 注册表由 SPACE ID / Binance 管理，其管理员可以直接发放 ID。一个 Binance 账户只能领一个 ID，但账户本身可能被买卖，所以"一个 ID 一份额度"不等于"一人一份"。
3. **参与依赖 Binance 的钱包产品。** 首发要用 Agentic Wallet 的开发者模式完成，受 Binance 的地区服务范围、风控规则、开发者模式每日额度（1,000 – 50,000 USDT）和余额上限约束，这些都不在协议控制之内。没有 Binance 账户的用户不能参与首发，但可以在买单簿买入。

补充：

8. **没有退款。** 买入即最终成交，开盘后价格可能跌破成本。
9. **开盘前只挡链上价格发现。** 链下 OTC 挡不住；两个 7702 账户之间还可以在一笔交易里原子地完成私下成交。合约钱包（Safe 等）开盘前不能参与首发，也不能转出代币。
10. **买单簿成交价可能低于开盘价。** 成交价最低为最新参与价的 90%，卖完后约在 1.35P 到买家出价之间，而开盘价是 2P。只靠自买自卖、付 2% 手续费就能刷出成交价，页面同时显示成交量。
11. **开盘抛压。** 卖完时参与者手里有 5,600,000 枚，池子里只有 2,800,000 枚；开盘时人人账面盈利，集中卖出可能让池子价格大幅下跌。
12. **货架压制早期上涨。** 开盘即有约 8 万枚货架供给，池子很难脉冲式上涨。
13. **开盘后可能出现第三方池子。** 任何人都可以用其他 Hook 或不用 Hook 另建池子；官方池以永久锁定的深度和官方 PoolId 标识为准，偏离的价格会被套利拉回。
14. **项目基金由项目方支配。** 20% 募集资金由 NFT 持有者提取和使用，收款地址可以随时修改，平台不做监管。NFT 转让时，未提取的部分付给转让前的收款地址，之后改为买方。
