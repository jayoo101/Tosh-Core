# 用 Binance Agentic Wallet 参与 ToshX 首发

ToshX 的创世首发只对持有 Binance Agent ID 的用户开放。Agent ID 绑定在你的 Agentic Wallet 上，而 Agentic Wallet 不能像 MetaMask 那样连接网页，所以首发要通过你的 AI agent 来完成。网页会把需要执行的每一步写成指令，你复制给 agent 就行。

---

## 一、准备（只需做一次）

1. **领取 Agent ID**：需要 Binance 账户、MPC 钱包和 Agentic Wallet。一个 Binance 账户只能领一个 Agent ID。
2. **安装 Agentic Wallet skill**：在 Claude Code、Codex 等 agent 工具里安装 Binance 的 `binance-agentic-wallet` skill，并登录你的 Agentic Wallet。
3. **调整钱包设置**：打开 Binance App → Agentic Wallet 管理页 → 右上角设置：

| 设置 | 改成 | 为什么 |
|---|---|---|
| 开发者模式 | 开启 | 只有开启后，agent 才能调用 ToshX 的合约。开启后有效 7 天，每次使用自动续期 |
| 开发者模式每日额度 | 高于你打算投入的金额 | 可选 1,000 / 5,000 / 10,000 / 50,000 USDT |
| 异常交易处理 | 需要确认 | 新发行的代币容易被判为"异常"，选"自动拒绝"会被直接拦下 |
| 可交易代币 | 全部 | 默认只允许白名单代币，新代币的授权、卖出和转账会被拒绝 |

注意：钱包总余额高于开发者模式额度时，开发者模式开不了。可以先把多余资金转出，或者选更高的额度。

4. **准备资金**：BNB 项目在 Agentic Wallet 里准备 BNB（另留一点 gas）；USDT 项目准备 USDT 和少量 BNB 作 gas。

---

## 二、创世买入

1. 打开项目页。没有连接钱包时，"用 Agent 执行"面板会自动展开。
2. 输入你想支付的金额，阅读并勾选风险确认。
3. 点"复制指令"，粘贴给你的 agent，例如："用我的 agentic wallet 执行下面这些合约调用"。
4. agent 会先预览（模拟执行），把结果和风险提示给你看。确认无误后告诉它执行。
   - USDT 项目有两步：先授权 USDT，再买入。
   - 如果 App 弹出确认请求，在手机上确认。
5. 回到网页，在面板第 3 步填上你的 Agentic Wallet 地址。页面会自动识别你的交易并刷新余额。

**几点说明**

- 买入后代币立刻到账，没有退款。
- 每个 Agent ID 有额度上限。付多了，超出额度或可售量的部分在同一笔交易里原路退回（BNB 项目）或不会被扣（USDT 项目）。
- 指令里的数量按当前价格生成，价格会随购买上涨。隔一段时间再执行，请回到网页重新复制。

---

## 三、开盘前卖出和转账

**卖给买单**：在项目的"市场"页选择卖出数量，复制指令给 agent。指令是两步：先授权代币给 ToshX 买单簿，再成交。卖家实收为成交额的 99%。

**转给其他钱包**：开盘前代币只能在钱包之间转，而且对方要先在 ToshX 登记收款地址：

- 对方参与过首发或挂过买单的，已经自动登记。
- 没登记的，在"我的持仓"里填对方地址，页面会生成一个登记链接，发给对方打开登记即可（一笔交易，几乎没有成本）。
- 用 Agentic Wallet 自带的"发送"时，对方地址要先加入 Binance App 的地址簿。
- 合约地址收不了币；Safe 等合约钱包开盘前也转不出币。

开盘之后这些限制全部解除，代币可以像普通代币一样自由转账和交易。

---

## 四、开盘后买货架

开盘后，项目页会出现"货架"面板。货架按固定价格出售新代币，价格从开盘价 2P 起逐档上涨，只有市场价涨到某一档时这一档才开放，所以货架价不会高于市场价。

- 货架和创世一样，**只卖给持有 Agent ID 的钱包**。每个 Agent ID 在每个项目上有终身额度：BNB 项目 0.7 BNB，USDT 项目 500 USDT，和创世额度分开计算。换钱包或换 ID 都拿不到新额度。
- 操作和创世买入一样：在面板里输入数量，点"用 Agent 执行"复制指令给 agent。BNB 项目先包装 WBNB 再授权，USDT 项目先授权，最后购买。
- 面板会显示当前档的价格、这一档还剩多少，以及你的剩余额度。
- 同一个区块里池子价格刚变动过时，货架购买会被拒绝（`SameBlockMintForbidden`）。等几秒，回到网页重新复制指令再执行。
- 货架付款的 80% 会自动买币加进项目池子，19% 归项目方，1% 进回购金库。

没有 Agent ID 的用户买不了货架，但可以直接在池子里买卖。

## 五、常见问题

| 现象 | 原因和处理 |
|---|---|
| agent 说"开发者模式未开启或已过期" | 在 App 里重新开启 |
| 错误 351804 | 钱包余额高于开发者模式额度，开发者模式被自动关闭。转出部分资金或调高额度后重新开启 |
| 错误 351807 | 超过开发者模式每日额度。在 App 里调高额度，或明天再试 |
| 错误 351818 | 交易需要确认，但钱包设成了自动拒绝。把"异常交易处理"改成"需要确认" |
| 错误 351803 | 被 Binance 风控拦截。不要重试，可以联系 ToshX 客服反馈 |
| 预览提示"execution reverted" | 多半是价格已经变化、额度已用完或创世已结束。回到网页刷新后重新复制指令 |
| 页面一直显示"正在等待交易" | 确认填的是 Agentic Wallet 的 BSC 地址；交易如果在 App 里待确认，确认后页面会自动刷新 |
