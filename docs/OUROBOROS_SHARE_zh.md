# Ouroboros（衔尾蛇）· 简介

**Ouroboros（衔尾蛇）** 是 BNB Chain 上的链上公平铸造玩法，口号是 **铸一分，烬一分**：L2 每铸出一份代币，底池同时销毁相同数量。

## 先看风险

- 实验性 meme / 链上玩法，不是理财、证券或存款。  
- 不承诺收益、回本或兑付；币价可以下跌，可以归零。  
- 请只用亏得起的钱。

## 基本信息

- 总量 **210 亿枚**，在 L1 结束时一次生成，之后只减不增；无预售、无团队预留。  
- 需要币安 `.ai` Agent ID；每个 ID 在 L1 + L2 合计最多 **30 份**。  
- 可用 **USDT 或 BNB** 支付；池子为 Pancake V2 TOKEN/USDT，LP 永久锁定。  
- 金库由 Safe 多签管理，地址在官网公布。

## 三个阶段

1. **L1（2 小时）**  
   每份 **0.9 USDT**，只限时间、不限总量。结束后 L1 参与者按份数平分 116.7 亿枚，另有 93.3 亿枚注入开盘池子，开盘价与 L1 每份成本相同。

2. **L1.5（开盘后至次日）**  
   铸造关闭，池子暂不交易，只能挂买单、不能挂卖单；没有买单时无法卖出。买单簿成交买卖各收 **2%**，进入金库。

3. **L2（次日开启）**  
   池子开放交易，按阶梯价铸造（1.2 USDT 起，共 2100 万份）。每笔铸造的 80% 加入流动性，并从底池销毁与用户所得相同数量的代币。铸出的代币 **180 秒**后可领取。

## 资金去向

- 铸造：**20%** → 金库，**80%** → 流动性  
- L1.5 买单簿：买卖各 **2%** → 金库  
- L2 起官方交易对：买入 **1.25%** 换成 USDT 进金库；卖出 **1%** 销毁

合约上线后会公布地址，请以链上已验证合约和官网公告为准。
